### What I've Built

**🤖 RAG Chatbot on GCP**
Internal Q&A chatbot combining Gemini 2.0 Flash intent classification with pgvector semantic retrieval and live HRIS API lookups. Served on Cloud Run with clickable source citations. Validated with a 22-case test harness at a 100% pass rate.

**🎯 AI Candidate Sourcing Platform**
TypeScript + Next.js platform embedding job descriptions and candidate profiles into PostgreSQL with HNSW indexing, ranking matches via LLM-based evaluation in seconds. Replaced 10+ hours of manual review per search across 15 users — blind spot-checks confirmed 9 of 10 top results as strong matches.

**📈 Stock Direction Predictor (Final Year Project)**
Fine-tuned FinBERT on 11,932 financial news samples, lifting test accuracy from a 53.3% baseline to 87.2% (F1 0.83). Integrated the sentiment signal into an XGBoost stock model and measured its real impact with a 4-fold walk-forward ablation across 11 stocks and 2,772 predictions — sentiment nearly tripled MCC (0.016 → 0.043).

**⚙️ Automation & Reporting Pipelines**
Rebuilt an OKR/KPI reporting pipeline to run unattended twice weekly on Cloud Scheduler, cutting a week-long manual process down to a 10-minute run covering ~540 records. Designed and maintain 9 production Zapier integrations across three SaaS systems, handling ~700 executions a month.
